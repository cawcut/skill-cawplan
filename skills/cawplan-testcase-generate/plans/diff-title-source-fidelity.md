### 1.2 Title 节 · 立「分拣式提炼」总姿势 + 收窄「不得照搬」

**位置**：L13–L16，在 `## Title` 首段之后、原 L16「不得照搬」段落**之前**插入新段；并**改写**原 L16 段落。

**在 L14 段落后插入**（新段落，标题用粗体引导）：
```markdown
**标题提炼 = 先分拣,再减法(分拣式提炼)**:

1. **先分拣 — 骨头(保真区)**:从父测试点里挑出**源逐字给定的具体值**,原样进用例 Title(展开后的 Expected 同理)。骨头**不动**:不意译、不概括、不因「提炼」而改写。
2. **再减法 — 肉(可砍区)**:只对**中间过程 / 导航路径 / 模糊词**做减法,下沉到 Step;骨头不随过程一起删掉。

**两步门(先问有没有,再决定保真还是尾巴)**:

- **门 1 — 源里逐字给了没有?** 父测试点或五字段里是否出现了可指认的具体句/码/数/枚举? **有 → 进门 2 保真**; **没有**(仅「给出明确提示」「应拦截」等方向性) → 走方向占位 + 诚实尾巴,**不许 AI 自己补一句像模像样的英文/错误码**。
- **门 2 — 保真区判定(认内容,不认引号)**:引号(`「」`/`""`)只是加分信号,**不是**判据。命中以下任一,且门 1 已确认源里真有 → **保真区**:
  - 像成句的提示/报错(尤其英文原文、首字母大写、像 UI 文案)
  - 错误码 / 状态码 / 枚举值(如 `404`、`Generation Failed`)
  - 具体数字阈值 + 单位(源里写了确切的数,如 `99`、`5 万字符`、`15s`)
  - UI 原词 / 按钮名 / 字段名(如 `Run`、`Separator`、`Index` — 与下文「该留」关键动作同类)
- **收口判据**:把这段抽象化之后,SQA 还能不能照着它去界面上一字一句核对?**不能了 → 说明砍掉了可核对信息 → 是保真区,不许砍、不许意译、不许挂尾巴。**
```

**改写**原 L16「不得照搬」段（替换整段）：
```markdown
**父测试点较长 / 含过程描述时,标题仍须重新提炼,不得照搬过程链**:父测试点标题(TestPointTitle)常把过程写进去(如"点击 Delete 后**应弹出确认弹窗,弹窗内点击 Delete 确认后**该项目应移除")。用例标题**不照搬这段中间过程** — 过程下沉到步骤,标题只留"触发 + 最终结果"。**但源逐字给定的具体值(提示文案/错误码/阈值等)不是过程,不得因「提炼」而删掉或改写**(见上「分拣式提炼」)。**继承列 TestPointTitle 原样保留**(溯源用);被提炼的只是**用例自己的 Title**,两者分工不同。
```

```markdown
    - **标题态**（`steps` / `expected` 为空）：**只查 `title`**；`expected` 为空不查。
    - **已展开**（本条有 `steps` / `expected`）：查 `title` **且** 查 `expected` 各行；Expected 里与验证点相关的具体文案须与源一致。

  - **呈现（硬修 vs 软提示）**：
    - **标题态 · `title` 问题 → 硬修**：与「块首行写了 `同上`」同级。**当场**按源写回 `cases[].title`、删错挂尾巴，再出预览。
    - **已展开 · `expected` 文案比对 → 软提示**：inline `⚠源已有文案未保留`，**不阻断、不自动覆写**（源句很长而某步只放关键片段等边界由 SQA 判断）。`title` 仍按标题态硬修。
```

## 5. 验收标准（执行后人工走查）

| # | 场景 | 父测试点 | 期望 `title` | 期望 `expected`（展开后） |
|---|------|----------|--------------|---------------------------|
| A | 回归用例（用户原报） | `…应提示「Some required input is missing.」` | 原句保留 | 原句保留，无尾巴 |
| B | 无引号成句 | `…应提示 Please connect a Text input.` | 原句保留 | 原句保留 |
| C | 仅方向性 | `…应失败并给出明确提示` | 可抽象 | 可 `(具体文案以实现为准)` |
| D | 父测试点已带尾巴 | `…应拦截并提示(文案以实现为准)` | 可延续抽象+尾巴 | 同左 |
| E | 过程+文案并存 | `点击 Run 打开配置面板后应提示「Saved.」` | 砍「打开配置面板」,留 `Saved.` | 留 `Saved.` |
| F | 源无文案 | 任意 | 不得 AI 编造英文原句 | 不得编造 |

**自检**：
- 标题态：A/B/E 的 `title` 无 `⚠源已有文案未保留`；C/D 不报警。
- 展开后：A/B/E 的 `expected` 无抽象替换、无错挂尾巴。
