# Support

## Get help

Open an issue on GitHub: <https://github.com/cawcut/skill-cawplan/issues>.

Include:

- What you ran or asked: the skill (for example `/cawplan-plan-track`), the
  `cawplan` command, or the MCP tool.
- Your client (Claude Code, Claude, Codex, Cursor, VS Code, ...) and whether you
  use the CLI or the MCP server.
- `cawplan --version` and your operating system, if you use the CLI.
- The error message or the unexpected output.

Do not paste tokens, the contents of `~/.cawplan/credentials.json`, ticket
content you are not allowed to share, or other private data into an issue.

## Before opening an issue

- CLI sign-in and common errors: [Troubleshooting](README.md#troubleshooting).
- MCP connection and sign-in problems: [MCP troubleshooting](MCP.md#troubleshooting).
- Install and role-based skill setup: [INSTALL.md](INSTALL.md).

## Security issues

Do not report security vulnerabilities in public issues. Follow
[SECURITY.md](SECURITY.md).

## Privacy

What the skills, the CLI and the MCP server send to CawPlan is described in
[PRIVACY.md](PRIVACY.md).
