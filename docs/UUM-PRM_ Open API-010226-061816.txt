Overview
The PRM (Product Release Management) Open API provides external systems access to PRM data. It uses API Keyauthentication without requiring JWT tokens or RBAC permissions.
Getting API Key
Please contact Neil.Wei or Dada.Chan to obtain an API Key.
Base URL
Authentication
All requests require the API Key in the Authorization header:
1https://core-api-gw.uid.alpha.ui.com
1Authorization: <your-api-key>

Linked Cases URL Whitelist
The linked_cases field only accepts URLs from these domains:
<https://ubiquiti.atlassian.net/> (Jira)
<https://ui.slack.com/> (Slack)
<https://ubnt.zendesk.com/> (Zendesk)
<https://community.ui.com/> (Community)
